# Components Package (`src/components`)

Thư mục này dùng để chứa các UI components tái sử dụng trong toàn bộ ứng dụng:
- **Common / UI Elements**: Các thành phần giao diện nguyên tử như `Button`, `Input`, `Modal`, `Dropdown`, `Badge`, `Card`, `Spinner`, `Toast`.
- **Layouts**: Các khối giao diện khung như `Header`, `Sidebar`, `Footer`, `Navbar`, `Container`.
- **Forms**: Các form nhập liệu tái sử dụng, bộ lọc tìm kiếm (Search bar, Filter group).
- **Feedback**: Thông báo lỗi, màn hình tải dữ liệu (Loading screen), thông báo trạng thái rỗng (Empty state).
