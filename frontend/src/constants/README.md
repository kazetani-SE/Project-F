# Constants Package (`src/constants`)

Thư mục này dùng để lưu trữ tất cả các hằng số tĩnh của ứng dụng:
- **Routes**: Danh sách đường dẫn URL (`ROUTES.HOME`, `ROUTES.LOGIN`, ...).
- **API Endpoints**: Danh sách URL gọi API backend.
- **Config**: Cấu hình phân trang (default page size), thời gian timeout, key lưu trữ `localStorage` / `sessionStorage`.
- **Enums & Mappings**: Các danh mục trạng thái, vai trò hoặc nhãn hiển thị cố định.
