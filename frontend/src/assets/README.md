# Assets Package (`src/assets`)

Thư mục này dùng để lưu trữ các tài nguyên tĩnh được import trực tiếp vào mã nguồn:
- **Images**: Logo, hình nền, banner, hình ảnh minh họa (.png, .jpg, .webp).
- **Icons / SVGs**: Các file vector icon hoặc đồ họa SVG.
- **Fonts**: Phông chữ tùy chỉnh nếu cần tải local.
- **Styles**: Các file style phụ trợ nếu có.
