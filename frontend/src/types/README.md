# Types Package (`src/types`)

Thư mục này dùng để định nghĩa toàn bộ kiểu dữ liệu TypeScript (Type System) của dự án:
- **Models / Entities**: Khai báo cấu trúc dữ liệu đối tượng nghiệp vụ.
- **DTOs (Data Transfer Objects)**: Kiểu dữ liệu Request Payload và Response trả về từ Backend API.
- **Common Types**: Các generic types dùng chung như `ApiResponse<T>`, `Pagination<T>`, `FilterParams`.
- **Component Props**: Có thể định nghĩa props phức tạp hoặc dùng chung giữa nhiều component.
